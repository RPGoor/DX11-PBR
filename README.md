# DirectX 11 Grass and Procedural Terrain Renderer

A real-time grass and procedural terrain rendering project built with **DirectX 11**, using **PBR lighting** and **ImGui** for interactive controls.

## Features

* Grass rendering
* Terrain generation
* Compute shaders
* PBR lighting
* Free-look camera
* ImGui controls
* HLSL shaders

## Dependencies
* DirectX 11
* Win32UI
* AssImp
* Dear ImGui
